# חיבור מערכות למערכת החיים (Intake API)

מערכות חיצוניות (Bossi, ובהמשך אחרות) שולחות לכאן לידים ושיחות. כל מערכת מקבלת מפתח משלה ב־`/life/settings` ← "מערכות מחוברות". המפתח מוצג פעם אחת בלבד, נשמר כאן רק כ־hash, ואפשר לבטל אותו בנפרד.

- **כתובת:** `POST https://yakov-eliya.vercel.app/api/intake`
- **כותרות:** `Content-Type: application/json`, `Authorization: Bearer lk_…`
- את המפתח שומרים במשתנה סביבה בשרת של המערכת (`LIFE_INTAKE_KEY`), לעולם לא בקוד שרץ בדפדפן. המפתח מאפשר רק לשלוח לידים ושיחות, ולא לקרוא שום דבר.

## ליד (בכל יצירה או עדכון)

```json
{
  "type": "lead",
  "event_id": "lead-123-2026-10-12T09:30:00Z",
  "lead": {
    "external_id": "123",
    "name": "משה כהן",
    "phone": "050-1234567",
    "email": null,
    "business_type": "יבואן כלי בית",
    "status": "hot",
    "notes": "ביקש הצעה אחרי החגים",
    "follow_up_date": "2026-10-14",
    "value": null
  }
}
```

`external_id` הוא המזהה של הליד במערכת השולחת. לפיו עדכונים נכנסים לאותו ליד.

שולחים הכל, והסינון נעשה כאן:

| status | מה קורה כאן |
| --- | --- |
| `new`, `cold` | נשאר רק ב־Bossi. אם הליד כבר מופיע כאן, השדות שלו מתעדכנים. |
| `hot` | מופיע ברשימת הלידים במסך העסק, עם מועד חזרה: `follow_up_date` אם נשלח, אחרת היום לפני 16:00 או יום העבודה הבא. בלי הודעה בטלגרם. |
| `won` | סגירה: הליד מסומן "לקוח", ונפתחת עסקה בשלב "נסגר" עם `value` בשקלים (או שעסקה קיימת מסומנת נסגרה). נשלחת הודעת 🎉 בטלגרם. |
| `lost` | אם הליד מופיע כאן, הוא מסומן "לא רלוונטי". אחרת, דילוג. |

## שיחה (אחרי כל שיחה)

```json
{ "type": "call", "event_id": "call-987", "count": 1, "date": "2026-10-12" }
```

המונה "שיחות / וואטסאפ" בפעילות המכירה היומית עולה ב־`count` (ברירת מחדל 1). ברירת המחדל של `date` היא היום, לפי שעון ישראל.

## תשובות

- `200` עם `{"result": …}`. הערכים האפשריים של `result`:
  - `created`, `updated`, `won`: הליד נקלט.
  - `ignored`: ליד קר, נשאר רק ב־Bossi.
  - `counted`: השיחות נספרו.
  - `duplicate`: אותו `event_id` כבר התקבל. בטוח לשלוח שוב אחרי תקלה.
- `400`: שדה חסר או לא תקין. ההודעה אומרת איזה.
- `401`: מפתח לא תקין או מבוטל.

מה הגיע לאחרונה, כולל שגיאות, מופיע בהגדרות תחת "מה הגיע לאחרונה".
